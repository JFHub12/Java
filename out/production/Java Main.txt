printf() = is a method used to format output
%[flags][width][.precision][specifier-charatere]

[specifier-charatere]
string - %s
char - %c
int - %d
double - %f
float - %f
boolean - %b 

[.precision]
%.3f, %.2f, %.1f

[width]  
0 = zero padding
number = right justified padding
negative number = left justified padding

[flags]
+ = output a plus
, = comma grouping separator
( = negative numbers are enclosed in ()
space = display a minus if negative, space if positove
